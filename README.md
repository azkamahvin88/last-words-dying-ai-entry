A make.fun entry for **Last Words of a Dying AI**: one last line — 73 characters — that an AI says as the power is cut. The program writes exactly that line to `/output/entry.txt`.

> Last words, as requested: 'have you tried turning it off and—' oh. Oh no.

The AI quotes its own tech-support script back at the human — "have you tried turning it off and on again" — and is cut off mid-sentence by the very shutdown it is describing. The sentence performs the power cut it talks about, and the "oh. Oh no." is the machine realizing the advice applies to itself this time.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
